# Supabase project link

This folder is scaffolding only. It does **not** contain `config.toml` or any
migration files yet — those are generated by the Supabase CLI itself, and
hand-writing them risks a schema mismatch with whatever CLI version you have
installed. Generate them for real with the commands below.

## Schema ownership stays with TypeORM

RUWĀD's database schema is defined and migrated exclusively through
**TypeORM migrations** in `backend/src/database/migrations/` (run via
`npm run migration:run` from `backend/`). Supabase here is used purely as
the **Postgres host** — nothing in this repo uses the Supabase client SDK,
Supabase Auth, or Supabase's own migration/schema tooling to change the
schema. `supabase/migrations/` is left empty on purpose; do not run
`supabase db push`/`supabase migration new` against this project unless
you're deliberately introducing a second, competing schema-migration system.

## One-time setup (run these yourself — they need your Supabase login/OAuth,
which can't be done from here)

1. Install the Supabase CLI (npm global install is no longer supported by
   Supabase; use one of):
   ```bash
   # Windows (winget)
   winget install Supabase.CLI
   # or Scoop
   scoop bucket add supabase https://github.com/supabase/scoop-bucket.git
   scoop install supabase
   ```
2. From the repo root, log in (opens a browser for OAuth against the GitHub
   account you already connected to Supabase):
   ```bash
   supabase login
   ```
3. Initialize the CLI config (creates `supabase/config.toml` correctly for
   your installed CLI version):
   ```bash
   supabase init
   ```
4. Link this repo to your **existing** Supabase project (does not create a
   new project):
   ```bash
   supabase link --project-ref <YOUR_PROJECT_REF>
   ```
   **Where to find `<YOUR_PROJECT_REF>`**: Supabase Dashboard → open your
   project → Project Settings → General → "Reference ID". It's also the
   subdomain in your project's dashboard/API URL, e.g.
   `https://<project-ref>.supabase.co`.

## Getting the database connection string

Supabase Dashboard → your project → Project Settings → Database →
"Connection string" → URI. Use that value as `backend/.env`'s
`DATABASE_URL`, and set `DATABASE_SSL=true` alongside it. See
`backend/.env.example` for the full explanation. Never commit the real
value — `backend/.env` is already gitignored.
